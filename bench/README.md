# Бенчмарки

## Файлы

| Файл | Что это |
| --- | --- |
| `prompt.txt` | сохранённый промпт из 4 GB проекта (~1 900 токенов, вопрос в конце). Используется для `chat` и `raw`. |
| `quality-prompts.json` | 22-промптный gate: арифметика, логика, код, tool loop, RU/DE/ES, длинный контекст. |

Промпт не менять между сравниваемыми сериями. Если меняем — это новая серия, а не
продолжение старой.

## Как запускать

См. `../docs/07-BENCHMARK.md`:

- 8 прогонов, первый — warm-up;
- устройство остыло, авиарежим, не на зарядке;
- `chat` и `raw` не смешивать;
- медиана + min/max;
- thermal status в каждой серии.

## Результаты

Сырые логи — в приложении (`logs/runs.jsonl`), сводка — в `../docs/07-BENCHMARK.md` или
в отдельном `results/` (создать позже). Старые строки не редактировать.

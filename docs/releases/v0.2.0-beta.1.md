# Lumen v0.2.0-beta.1

**The first real beta.** Local GGUF inference on a 6 GB Snapdragon phone, with
no cloud and no mock chat backend.

- APK: `lumen.apk` (3.32 MB, arm64-v8a, Android 13+)
- SHA-256: `4CF09E6E54609AFDBDF60A23E9B391FAD949423466C8E257964C0D5808244C88`
- Device used for the numbers below: Xiaomi MI 8 (`dipper`), Snapdragon 845,
  Adreno 630, 6 GB RAM, Android 15.

## Highlights

### Real engine

- Rust `LlamaEngine` + JNI `start / poll / cancel / prepare / unload`.
- Streaming tokens, stop, unload, Android `onTrimMemory` → KV/weights release.
- Runtime LoRA through `llama_set_adapters_lora`.
- No `engine() == "mock"` path in the app.

### Measured on the MI 8

| Model | Quant | Result |
| --- | --- | --- |
| Qwen2.5 0.5B Instruct | Q4_K_M | 18.8 tok/s, 370 ms TTFT |
| Ternary-Bonsai 2-4B + LoRA | Q2_0 | 2.5 tok/s, 4.0 s TTFT, 115 tok |
| Clover 35B-A3B APEX-I-NanoPlus | Q4_0 | 0.7 tok/s, 11.1 s TTFT, 92 tok, 3.1 GB PSS |

Clover used mmap and page cache on a phone with less RAM than the 11.69 GB
file. That is the point of the MoE path.

### Hugging Face browser

- Public GGUF search, author filter (case-insensitive), sort by relevance,
  downloads, likes, updated and created.
- Favorites, file list with sizes, RAM envelope, download progress, resume,
  cancel, free-space check.
- Gated model token stored in app preferences.

The MI 8 had no Wi-Fi during the final build, so the network path was not
exercised on-device; the UI and JNI bridge are in the APK and compile cleanly.

### Chats

- Local persistence (`lumen.chats.v1`), per-chat message storage.
- Today / Yesterday / Previous 7 days groups.
- `<think>` reasoning is collapsed into a readable block.
- Chat header shows the chat title, not the model name.
- New chat creates a real entry; first message becomes the title.

### Icon, splash, brand

- New **Lumen** identity: hand-drawn L mark + mint dot, no AI glow, no gradients.
- Adaptive Android icon, legacy mipmaps, native launch screen and HTML splash.
- Dark, light, night and AMOLED themes.

## Known limitations

These are not hidden behind fake buttons:

- **LiteRT-LM / Gemma 4 E4B** is not implemented in this APK.
- **MTP draft, DFlash, DSpark** are not exposed by the FFI.
- **GPU / NPU** are not built; this is a CPU-only APK.
- **mmproj / vision** is detected in the registry but the engine rejects it.
- **Hugging Face live network test** is pending (phone had no Wi-Fi).
- Folders, per-chat overrides, attachments, FGS and SAF import are next.
- Gemma 4 E4B on a 6 GB MI 8 is memory-risky; the research report recommends
  E2B for that device.

## Install

```powershell
adb install -r lumen.apk
```

Models live in:

```
Android/data/dev.snapdragonllm/files/models/
```

The app scans that directory on launch. No model is bundled in the APK.

# 06 — Дорожная карта

## Статус на 2026-11-07

- **Phase 0** — профиль MI 8 заполнен (`docs/device-845.md`): CPU/dotprod, RAM,
  GPU, thermal, 4 KB pages. Baseline PocketPal/AI Edge Gallery ещё нет;
  микробенчмарки UFS/RAM ещё нет.
- **Phase 1** — нативное приложение и CPU-ядро работают: Qwen2.5-0.5B,
  release APK, чат, Tuning, JSONL, телеметрия. 30-минутный sustained ещё нет.
- **Phase 2** — OpenCL собран и измерен: в 12–14 раз медленнее CPU на Adreno 630
  (`docs/14-BACKENDS.md`). Vulkan не собран.
- **Phase 3** — Clover 35B-A3B загружается и отвечает: 2.4/0.6 tok/s.
  Экспертный кэш/per-layer prefetch ещё не сделан.
- **Phase 4–6** — не начаты; quality gate, тернарные, 16/24 GB впереди.

## Правило

Этап закрыт, когда есть **артефакт** (код, лог, документ) и **измерение**, а не когда
«кажется, работает». Числа не выдумываются: до Phase 0 в плане стоят TBD.

## Phase 0 — Профилирование и baseline (1–2 недели)

**Цель:** узнать, что реально умеет 845, и получить точку отсчёта.

- [ ] Заполнить `docs/device-845.md`: `getprop`, `/proc/cpuinfo`, `/proc/meminfo`,
      `dumpsys meminfo`, `dumpsys thermalservice`, `df`, GPU/OpenCL/Vulkan info.
- [ ] Проверить `asimddp`, `fp16`, `crc32`; 64-bit; 16 KB pages (если Android 15+).
- [ ] Установить PocketPal AI и Google AI Edge Gallery; запустить маленькую модель
      (SmolLM2-135M или Qwen2.5-0.5B); записать TTFT/decode/память/тепло.
- [ ] Собрать llama.cpp CLI под `arm64-v8a`; запустить ту же модель; сравнить.
- [ ] Замерить пропускную способность RAM (memcpy) и UFS (seq/random 4K/1–2 MB).
- [ ] Проверить, видит ли приложение OpenCL-устройство и Vulkan 1.1.
- [ ] Записать бюджет памяти: сколько реально доступно процессу на 6 GB.

**Выход:** документ с числами и ответом «Clover на 845 вообще имеет смысл или только
как демо стабильности».

## Phase 1 — Нативное приложение + CPU-ядро (2–4 недели)

**Цель:** свой чат работает офлайн на маленькой модели, всё логируется.

- [ ] Android-проект (Kotlin, Compose), `arm64-v8a`, foreground service.
- [ ] C++ ядро `libsnapdragonllm`: загрузка GGUF, токенайзер, sampler, chat template.
- [ ] JNI-API: `load`, `generate`, `cancel`, `unload`, `config`.
- [ ] Менеджер моделей: импорт/скачивание, SHA-256, свободное место.
- [ ] Экран чата; экран Developer; JSONL-логи; экспорт.
- [ ] CPU backend (NEON), Qwen3-4B / Llama-3.2-3B.
- [ ] 30 минут непрерывной работы без OOM.

**Выход:** APK, который на 845 отвечает на вопросы, и лог с TTFT/decode/памятью.

## Phase 2 — GPU-бэкенд (2–4 недели)

**Цель:** понять, даёт ли Adreno выигрыш, и на чём именно.

- [ ] Vulkan backend: dense на GPU, эксперты на CPU.
- [ ] OpenCL (Adreno) как второй вариант; переключатель `backend`.
- [ ] `gpu_layers`, `threads`, `prefill_chunk` — в конфиге.
- [ ] A/B CPU vs Vulkan vs OpenCL на prefill и decode, на 845 и 8 Gen 3.
- [ ] Автоподбор: классификация GGUF, оценка бюджета, 20–30 с калибровка, профиль
      `model+device`.
- [ ] Решение: какой backend по умолчанию на каждом устройстве.

**Выход:** таблица «prefill/decode по бэкендам»; явное решение, а не вера.

## Phase 3 — Экспертный кэш и Clover (3–6 недель)

**Цель:** Clover работает на 845 без падений; hit rate и скорость измерены.

- [ ] Разметка GGUF: где эксперты, где dense, размеры blob.
- [ ] Профиль горячих экспертов; per-layer слоты; LRU/aging.
- [ ] Prefetch следующего слоя; батчинг чтений; `madvise`.
- [ ] Memory governor: бюджет, `onTrimMemory`, освобождение GPU-кэша.
- [ ] Clover: 2K → 8K → 32K; 10 минут стабильно.
- [ ] Отчёт: hit rate по слоям, SSD MB/токен, decode tok/s, thermal.

**Выход:** честный ответ, играбелен ли Clover на 845 и что даёт кэш.

## Phase 4 — KV, prefill, спекуляция (2–4 недели)

- [ ] `q8_0` / `q4_0` KV, flash attention (если есть).
- [ ] Заимствование prefill-буферов под кэш между запросами.
- [ ] n-gram speculation; при наличии — MTP/draft.
- [ ] Quality gate: 22 промпта + мобильные (tool call, JSON, RU/EN, длинный контекст).
- [ ] Сравнение с базовой линией PocketPal на той же модели.

**Выход:** KV-квант проходит quality gate; спекуляция либо ускоряет, либо выключена.

## Phase 5 — Тернарная ветка (2–4 недели)

- [ ] TQ1_0/TQ2_0: загрузка, CPU-ядра, определение типа.
- [ ] BitNet b1.58 2B4T (или другой доступный TQ-чекпоинт).
- [ ] Качество: короткий gate + сравнение с Q4-версией.
- [ ] Решение: нужен ли GPU-кернел для TQ.

**Выход:** тернарная модель запускается и отвечает; известна цена по качеству.

## Phase 6 — 16/24 GB и NPU (после первых чисел)

- [ ] Прогон той же матрицы на Pad 2 (16 GB) и OnePlus 13 (24 GB).
- [ ] Подбор слотов/контекста под каждый объём RAM.
- [ ] Исследование QNN/Genie: какие модели реально поддерживаются.
- [ ] Релизная сборка, лицензии, документация.

## Риски

| Риск | Вероятность | Что делаем |
| --- | --- | --- |
| 845 слишком медленный для Clover | высокая | оставляем как demo стабильности; фокус на 16/24 GB |
| Adreno 630 драйвер нестабилен | средняя | CPU fallback, отключение GPU по устройству |
| Android LMK убивает процесс | средняя | memory governor, резерв, foreground service |
| Thermal throttling 2× | высокая | sustained-замеры, ограничение потоков |
| TQ-качество неприемлемо | средняя | тернарная ветка как отдельный режим, не default |
| QNN не поддерживает MoE | высокая | NPU не в критическом пути |
| 11.69 GB не влезает на телефон | средняя | проверка свободного места, стриминг, меньший квант |

## Чего не делаем

- Не портируем CUDA-код и не ждём «CUDA на Android».
- Не публикуем tok/s без протокола `07-BENCHMARK.md`.
- Не называем изменение улучшением без quality gate.
- Не кладём модель в APK.
- Не считаем «6 GBRAM» бюджетом приложения.
- Не оптимизируем под 8 Elite до того, как работает 845.

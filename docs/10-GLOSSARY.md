# 10 — Словарь

| Термин | Значение |
| --- | --- |
| **MoE** | mixture-of-experts: на каждый токен роутер выбирает несколько экспертов из многих |
| **Dense** | веса, которые используются всегда (attention, shared expert, embeddings, head) |
| **Router** | слой, выбирающий экспертов для токена |
| **top-k** | сколько экспертов выбирает роутер (у Clover 8 из 256) |
| **Expert hit rate** | доля выбранных экспертов, найденных в кэше без чтения с SSD |
| **Per-layer cache** | квота слотов на каждый слой, а не общий пул |
| **Prefill** | обработка промпта (много токенов сразу) |
| **Decode** | генерация по одному токену |
| **TTFT** | time to first token, время до первого токена |
| **KV cache** | кэш ключей/значений внимания; растёт с контекстом |
| **KV q8_0/q4_0** | квантование KV-кэша (8/4 бита) |
| **Flash attention** | оптимизированное внимание, меньше памяти/трафика |
| **mmap** | отображение файла в память; страницы подгружает ОС |
| **page cache** | кэш страниц файлов в RAM, которым управляет ядро |
| **UFS 2.1 / 4.0** | стандарт флеш-памяти телефона |
| **Unified memory** | GPU и CPU делят одну RAM (Android/Snapdragon) |
| **PSS / RSS** | метрики памяти процесса (shared/private) |
| **LMK** | Low Memory Killer — механизм Android, убивающий процессы при нехватке RAM |
| **TQ1_0 / TQ2_0** | тернарные форматы ggml (~1.58 / 2 бита на вес) |
| **BitNet b1.58** | модель, обученная с весами {-1, 0, +1} |
| **Adreno** | GPU Qualcomm |
| **Hexagon** | DSP/NPU Qualcomm |
| **QNN / Genie** | Qualcomm AI Engine Direct / Genie — стек для NPU |
| **Vulkan / OpenCL** | GPU API, доступные на Android |
| **NEON / dotprod / i8mm** | SIMD-расширения ARM для CPU-ядер |
| **Backend** | вычислительный путь: cpu / vulkan / opencl |
| **Speculation** | предложение нескольких токенов и проверка их одним проходом |
| **MTP** | multi-token prediction: draft-голова модели |
| **Gate** | набор проверок качества перед релизом |

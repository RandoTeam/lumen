# SnapdragonLLM — UX/IA и дизайн-система (полная версия)

Источник: исследование UX/UI, 2026-11-08. Приложение переписывается на Rust.

## TL;DR

- **Главный экран — Chats, а не пустой чат и не модели.** На телефоне 3 корневых
  раздела: **Chats, Models, Settings**; чат — push-экран. На планшете — rail +
  список чатов + беседа.
- **Никакого hamburger как основной навигации.** История чатов — главный объект
  приложения; прятать её в drawer нельзя. Hamburger/overflow — только для
  вторичных действий.
- **Clover 11.7 GB — не герой онбординга.** Первый запуск ведёт к Qwen 0.5B
  (0.4 GB, 25 tok/s); Clover — отдельная карточка «12 GB+, 0.6 tok/s на MI 8,
  streaming с диска» и только по явному тапу.
- **Два взрослых направления:** **Paper & Ink** (светлое) и
  **Graphite & Ember** (тёмное). Один акцент, тёплые нейтрали, 1 px borders;
  без градиентов, неона, свечения и «AI-искр».
- **Состояние модели честное, но не шумное:** model pill в композере, 2 px
  context meter, stat line после ответа.

Что видно у конкурентов: ChatGPT использует sidebar/Recents и iPad split view,
но на телефоне история спрятана; Gemini — 5 пунктов + «More» и единые Settings,
но drawer остаётся единственным входом; Claude экспериментирует с bottom nav;
Copilot убрал bottom tabs в пользу chat-first + hamburger — фичи стали хуже
находить; Perplexity даёт понятные нижние разделы; LM Studio/Jan — явный model
loader; PocketPal и AI Edge Gallery — model-first онбординг. **Беру:** chat-first,
split view, честный model state, 3 раздела. **Не беру:** model-first home,
hamburger-only, 5+ вкладок, desktop-плотность на телефоне.

## IA телефона

**Каркас.** 3 корневых раздела: **Chats, Models, Settings**. Chat — не вкладка,
а push из списка, поиска или уведомления. Search — overlay, New chat — действие,
Developer — скрытый экран. Bottom nav: 3 item, 80 dp + system inset, icon 24 dp,
label 11 sp, active accent; без pill-подсветки и без FAB. На MI 8 (393×818 dp)
это 3×~131 dp — свободно, targets ≥48 dp.

**Почему не hamburger.** Drawer скрывает Recents — то, ради чего приложение
открывают. Почему не 5 вкладок: Models и Settings низкочастотны, Studio —
условный раздел. Верхний бар: back / крупный заголовок 32/40, search 48,
compose 48, overflow. Заголовок сворачивается в 56 dp при скролле.

**Home / Chats.** Сверху: Search (разворачивается inline), строка «New chat»,
фильтры All / Pinned / Archived. Секции: Pinned, Today, Previous 7 days, Older.
Строка 72 dp: title 15/20 500, snippet 13/18 secondary в одну строку, model +
time 12 справа. Пустое состояние: «No chats yet», два действия — Start a chat,
Import model. Никакого hero-логотипа.

**Поиск.** Глобальный FTS по заголовкам и сообщениям; результаты группами Chats /
Messages / Models; snippet с подсветкой; фильтры model/date; recent searches.
В чате — отдельный in-chat search из overflow: счётчик, up/down, подсветка.

**Новый чат.** Создаёт draft сразу, без диалога. Модель = последняя
использованная; если модели нет — sheet с рекомендованными и Import. Загрузка
не блокирует композер: статус-карточка с фазами Open → Map → Context → Warm и
Cancel.

**Что на главном.** Только библиотека чатов, поиск, new chat, компактный engine
status (если модель загружена/генерирует) и предупреждение о свободном месте при
<2 GB. Ни телеметрии, ни tok/s, ни графиков.

**Developer.** Settings → About → 7 тапов по версии; в debug — всегда. Не
вкладка. Внутри: logs, telemetry, raw config, benchmark, safe mode, copy
diagnostics.

## IA планшета

**Размеры.** Pad 2: 2120×3000 px при плотности ~2.0 → ~1060×1500 dp. Оба
положения — expanded (≥840 dp), значит две панели нужны и в портрете.

**Каркас.** Rail 80 dp + list 340 dp + conversation (max 720 dp). Портрет 1060:
rail 80 + list 300 + chat 680. Ландшафт 1500: rail 80 + list 340 + chat 760 +
Context 320 (опционально). Rail: сверху New chat 48, затем Chats, Models, Studio
(только если image-pack установлен и ≥12 GB), снизу Settings. Item 56 dp,
icon 24, label 11; активный — 3×20 accent bar. Expanded rail 240 dp — только по
кнопке, не автоматически.

**Two-pane.** Выбор чата обновляет правую панель; список не исчезает. Пустая
правая панель: «Select a chat or start a new one» + 3 prompt cards. Divider 1 dp,
list resizable 280–420 dp. В чате нет внутренних табов. Models и Settings — тоже
list-detail: список слева, детали справа; при 1060 dp Settings может быть одной
колонкой max 720.

**Ориентация.** Не лочить. При повороте сохранять selected chat, scroll, draft,
открытую sheet. В портрете Context — side sheet/overlay; в ландшафте — третья
панель. При 600–839 dp — bottom bar + одна панель; при <600 — телефонный каркас.

**Ширина.** Chat text max 720 dp (68–76 знаков), composer max 760, forms 640,
model grid: 2 колонки 840–1199, 3 — 1200–1599, 4 — ≥1600, card min 280. Лишнее
пространство — симметричные поля, не растянутый текст.

**Back.** На expanded back из чата не сбрасывает selection (уходит из
приложения/на home); на compact — возвращает к списку. Predictive back
анимирует именно это.

## Экраны

### Чат

**Top bar:** back, title (tap — rename), subtitle «Clover 35B · 0.6 tok/s · 4K»
только когда модель активна, overflow: search in chat, export, clear, system
prompt, branch.

**Сообщения.** Assistant — full-width текст на canvas, avatar 24 и имя модели;
user — bubble surface-2 справа, max 82%. Markdown: заголовки, списки, таблицы,
ссылки (внешние — с подтверждением), code block: surface-2, 1 px border, mono 13,
language label, copy всегда видим, collapse после 20 строк. Timestamps 12 sp,
показывать по long-press; группировка сообщений 8 dp, между группами 20.

**Действия.** Phone — long-press → контекстный sheet: Copy, Edit, Regenerate,
Branch, Share, Read aloud. Tablet — hover-reveal icon row. Regenerate создаёт
ветку, старую не затирает; в шапке появляется «2/3 ← →». Edit user message
создаёт ветку и предупреждает, что последующие сообщения останутся в старой.
Copy — raw markdown.

**Composer.** Multiline 1–8 строк, placeholder «Message Clover…», attach `+`,
model pill слева, send/stop справа. Пока идёт генерация, send превращается в
Stop; черновик сохраняется. Если нажать send во время генерации — диалог
«Stop and send?», без скрытой очереди. Над композером — 2 px context meter,
появляется после 60%: «76% · 3,120 / 4,096». Tap — sheet с Explain / Summarize
older / New chat / Increase context.

**Вложения.** Photo, Camera, File, Audio, Video. Каждый пункт disabled, если
capability нет, с причиной: «Requires vision model (mmproj)». Превью 64 dp,
video — duration + «8 frames at 384 px», audio — waveform + duration, «30 s
chunks». Лимиты и оценка RAM показываются до отправки. Image → mmproj; video →
MediaCodec frames → VLM; audio → Whisper; TTS — системный.

**Streaming.** Текст коалесится раз в 80–120 ms, не на каждый токен; caret 2 px
accent. Автоскролл только если пользователь внизу; иначе — pill «Jump to
latest». Stop отзывается ≤200 ms, partial сохраняется и помечается «Stopped
after 312 tokens». Stats обновляются 2 раза/с, после завершения — строка
«24.1 tok/s · 312 tok · TTFT 4.2 s · context 38%».

**Пустое состояние.** «Ask anything» + 4 chips (Summarize, Explain, Write,
Translate) + capability hint. Если модели нет — карточка Setup model, не пустой
экран.

**Ошибки.** Inline card над композером, title человеческим языком, detail
раскрывается, run_id копируется. Примеры: OOM — «Clover needs ~2.3 GB active
RAM; 1.1 GB free. Try 2K context or Qwen 0.5B»; context overflow — «4,096-token
limit reached» + Summarize / New chat / Increase; bad GGUF — «File is incomplete
or not GGUF. Re-import (SHA mismatch)»; thermal — «Device is hot; speed limited.
Pause 2 min or lower threads».

**Длинный контекст.** Meter, Summarize older, branch, outline sheet со списком
user-промптов (на планшете — collapsible rail внутри беседы). При 100% композер
блокируется с действиями, а не молча обрезает историю.

### Models

**Список.** Сверху: занято/свободно, Import, Get models. Фильтры All / Text /
Vision / Audio / Image. Строка: монограмма 40, имя, файл 12, размер, quant,
capability chips, RAM estimate, статус Ready / Needs mmproj / Incomplete /
Too large. Сортировка: Ready → размер.

**Детали.** Имя, quant, размер; Load; сетка: параметры, context train, file size,
active RAM, KV, backend, license/source, SHA. Capabilities: Text / Vision /
Audio / Video — supported или «Add mmproj 0.6 GB». LoRA: список адаптеров,
scale 0–1, attach, compatibility check; «LoRA affects text only, not vision
projector». Профиль `model+device`: SoC, RAM class, backend, ctx/threads/KV/flash,
измеренные TTFT/decode/thermal; Reset / Recalibrate (20–30 s, можно Skip).

**Preflight.** Пример Clover: «File 11.69 GB (mmap, evictable) · Active ~2.3 GB ·
KV 0.4 GB @4K». На 6 GB: «Expect 0.6 tok/s, heavy UFS reads, thermal throttling;
not for daily use». Кнопки: Load anyway / Use 2K / Choose smaller. Qwen:
«0.37 GB · ~0.5 GB active · 25 tok/s · Recommended». Preflight-чеклист: file,
SHA, GGUF header, arch, mmproj, free disk, available RAM, thermal, backend —
green/amber/red и одно действие на проблему. Автозагрузка только ≤2 GB и по
тумблеру; 4 GB-порог сохраняется как жёсткое правило.

**Импорт.** SAF multi-select `.gguf`, staging `.part`, прогресс % + MB/s + SHA,
отмена, проверка `size × 1.15 + KV + compute`, duplicate by SHA, atomic rename.
Удаление: confirm с именем и размером; активную модель сначала Unload. Пакеты:
Text / Vision / Audio / Image; отсутствующий файл пакета виден, а не скрыт.

### Settings

Шесть групп, без вложенных лабиринтов:

1. **Generation:** temperature 0.7, top-p 0.95, top-k 40, max tokens 512,
   repeat 1.1, seed, system prompt; «per-chat override»; Reset.
2. **Performance:** threads (4/6 по big-ядрам), context 2K/4K/8K/16K с оценкой
   KV, batch 128, KV q8_0/f16, mmap on, mlock off, flash on, GPU layers,
   backend CPU/GPU/NPU; budget bar; «Apply reloads engine, chat preserved»;
   Recalibrate.
3. **Storage:** models 13.2 GB, chats, logs, cache; free space; Clear cache/logs;
   Export chats; storage location.
4. **Appearance:** System / Paper & Ink / Graphite & Ember; text size; density
   (tablet); chat width; reduce motion; code font size.
5. **Privacy:** offline badge, telemetry off, prompt logging off, chat storage
   path, biometric lock (future), Delete all chats, «no network permission».
6. **Developer (hidden):** logs, telemetry, raw config JSON, engine flags,
   benchmark, crash reports, safe mode, copy diagnostics; баннер «может сломать
   модели».

About: версия, лицензии, source, device info, updates через файл.

### Остальные

Search overlay, Import flow, Model detail, Settings detail, Developer,
About/Licenses. Studio — не вкладка: появляется в rail только при установленном
image-pack и ≥12 GB; на телефоне — flow из `+` → «Generate image».

## Доступность

- **Контраст:** body ≥4.5:1, large/UI ≥3:1; проверить оба theme и
  disabled-состояния. Accent не заменяет текст и иконку.
- **48 dp:** все tap targets, даже если визуально 32–36; между ними ≥8 dp.
  Icon buttons — 48×48 с 24 dp glyph.
- **IME:** `WindowInsets.ime` + `imePadding`; композер поднимается над
  клавиатурой; bottom nav скрывается при открытой IME на телефоне; back сначала
  закрывает клавиатуру. На планшете rail остаётся, контент не прыгает.
- **Screen reader:** список сообщений — semantics list, «You said» / «Clover
  said»; streaming live region обновляется не чаще раза в 2 s, не на каждый
  токен; у Canvas-иконок contentDescription; model chip читается как «Model
  Clover 35B, 4K context, loaded».
- **Predictive back:** Android 14+ `OnBackInvokedCallback`; back из чата →
  список с сохранённой позицией; back из sheet → dismiss; back во время
  генерации не отменяет её (генерация живёт в foreground service), отмена —
  только Stop.
- **Font scale:** 1.3× и 2.0× без обрезки; кнопки растут, bubbles wrap, stat line
  переносится. **Keyboard:** Tab/arrows/Esc, Ctrl+K — search, Ctrl+N — new chat,
  Ctrl+Enter — send. **Reduce motion**, без autoplay video/audio.

## Онбординг: первые 30 секунд

- **0–5 s.** Один экран: «Private AI on this device». Три факта: работает
  офлайн, чаты остаются здесь, аккаунт не нужен. Одна кнопка Continue,
  вторичная — Restore chats.
- **5–15 s.** Карточка устройства: «OnePlus Pad 2 · 16 GB · Snapdragon 8 Gen 3».
  Модели: **Qwen 0.5B** — 0.4 GB, 25 tok/s, «Fast start» (выбрана по умолчанию);
  **Ternary Bonsai 2.4B Q2_0** — 1.2 GB, «Balanced»; **Clover 35B-A3B** —
  11.7 GB, «Maximum quality · 12 GB+ · 0.6 tok/s on MI 8». Clover — под «Large
  models», не в первом ряду. «Use existing file» — SAF.
- **15–25 s.** Необязательная калибровка: «Measure this device (20–30 s)» +
  Skip. Объяснить в одной строке: подберёт threads/context. Без театра
  бенчмарков.
- **25–30 s.** Home с композером и 3 prompt chips. Модель грузится при первом
  send с фазами и Cancel; notification permission спрашивается при первой
  генерации, не на старте.
- **12 GB не пугает:** показывать «File 11.7 GB on disk · Active RAM ~2.3 GB», а
  не «needs 14 GB RAM»; не автозагружать; требовать тап и подтверждение; рядом —
  «Try Qwen first». Никакой загрузки 12 GB до первого чата.

## Анти-паттерны

- Лаймовый неон, градиенты, glow, glassmorphism, «AI sparkles»; логотип-герой
  внутри приложения.
- Hamburger-only навигация и 5+ вкладок; чат как единственный экран без списка.
- Models как главный экран; онбординг, требующий 12 GB-модель; авто-загрузка
  Clover на 6 GB.
- Фейковый прогресс, фейковые tok/s, бесконечные пульсации и shimmer.
- Сырые ошибки (`llama_load_model_from_file failed`) и JSON в UI; модалки на
  каждую мелочь.
- Цвет как единственный статус; 32 dp кнопки; текст 10 sp.
- Автоскролл, вырывающий чтение; autoplay audio/video.
- Удаление модели без unload/подтверждения; потеря чата при kill.
- Дублирование model picker в трёх местах; скрытые capabilities; image attach
  на text-only модели с падением после отправки.
- Три уровня настроек с необъяснёнными тумблерами; «tokens» без расшифровки в
  первичном UI.
- Копирование ChatGPT/Claude один-в-один: серые пузыри, центр-логотип, безликий
  «AI look».

## Что проверить на устройствах

**MI 8 (393×818 dp, 6 GB):** нижний nav + IME; достижимость большим пальцем;
200 сообщений — 60 fps; font scale 1.3/2.0; контраст на улице; cold start
≤1.5 s; predictive back; OOM-путь Clover; 0.6 tok/s и нагрев 10 мин; импорт с
отменой; RU-строки.

**Pad 2 (1060×1500 dp портрет / 1500×1060 ландшафт, 16 GB):** rail + list + chat
на 1060; поворот с сохранением draft/scroll/selection; 720 dp строка — длина
68–76 знаков; resize list 280–420; Context pane в ландшафте и side sheet в
портрете; split-screen 600–839 dp; клавиатура и Ctrl-шорткаты; preflight
Clover; 2 колонки model grid; 120 Hz motion; 48 dp на всех кнопках; Paper & Ink
и Graphite & Ember в реальном освещении.

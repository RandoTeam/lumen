# Материалы из 4gbVramStrata

Эти документы скопированы из проекта `C:\VietnAi\4gbVramStrata` как **источник идей**,
а не как доказательства для Android.

- `HOW_IT_WORKS_MODELS.md` — как устроены Clover и экспертный кэш.
- `BENCH-4GB.md` — протокол измерений на 4 GB CUDA-ноутбуке.
- `QUALITY-4GB.md` — 22-промптный gate и поведение моделей.
- `clover-config.json` — конфиг запуска Clover в 4 GB проекте (пример ручек).
- `clover-chat-result.json` — пример записи замера (не эталон для Android).

**Важно:** все числа в этих файлах сняты на ноутбуке с отдельной VRAM (RTX 3050 4 GB),
CUDA и 32 GB RAM. На Snapdragon другая память (unified), другой GPU и другая ОС. Числа
нельзя переносить; переносятся механизмы и правила измерений.

Актуальная версия — в исходном репозитории; здесь копия на момент 2026-11-07.
